# Objetivos y celebraciones de Alicante

Esta propuesta añade avisos protegidos para objetivos y cierres de tratamientos de importe relevante.

- No mezcla datos con Murcia: todas las consultas exigen organización y clínica de Alicante.
- No modifica citas, pacientes, pagos ni presupuestos existentes.
- Las felicitaciones personales solo consideran presupuestos superiores a 1.300 €, totalmente liquidados y aceptados después de activar la función.
- El reconocimiento personal llega únicamente al chat del profesional de la valoración y de la persona de recepción o auxiliar que presentó el presupuesto.
- La fiesta visual y el sonido se reservan para objetivos mensuales alcanzados; no se activan por citas, cobros aislados ni avances horarios.
- Cada destinatario confirma individualmente el aviso desde su chat interno.
- Dirección y Gestión pueden configurar el sonido de las celebraciones de objetivos.

La migración debe validarse primero en el proyecto sintético de Alicante y, después, aplicarse a producción.
