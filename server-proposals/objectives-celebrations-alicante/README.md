# Objetivos y celebraciones de Alicante

Esta propuesta añade avisos protegidos para objetivos, avances horarios y cierres de tratamientos.

- No mezcla datos con Murcia: todas las consultas exigen organización y clínica de Alicante.
- No modifica citas, pacientes, pagos ni presupuestos existentes.
- Las felicitaciones personales solo consideran presupuestos aceptados después de activar la función.
- Cada destinatario confirma individualmente **He visto el aviso**.
- Dirección y Gestión pueden configurar sonido y frecuencia.

La migración debe validarse primero en el proyecto sintético de Alicante y, después, aplicarse a producción.
